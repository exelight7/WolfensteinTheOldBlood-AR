Bundled release resources live here.

- `localization/` — off-line localization payload (`manifest.json` + `chunk0.index` +
  `chunk0.resources` + `graphicsdriverwarningloc.json`) generated by the release build.
- `sidecar/wtob-build.exe` — optional builder sidecar that reconstructs the payload from
  the user's own vanilla game files when a downloaded package is not available.

Neither directory is committed with proprietary game data. The public release workflow
populates them from the localization sources and the sidecar build.

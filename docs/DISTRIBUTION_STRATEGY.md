# Distribution strategy

Distribute original tooling, Arabic data and licensed project font derivatives only. Full game archives, extracted original fonts/textures and complete English tables remain local.

Experimental approach implemented locally: append generated replacement payloads to the user's own chunk0 archive and update selected offset/size fields in its index. Original archive contents remain local. Structural build/install/restore checks pass; actual game loading remains UNVERIFIED. No generated game archives or English runtime table are published.

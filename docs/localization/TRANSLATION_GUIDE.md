# Translation guide

Use natural Modern Standard Arabic. Preserve tone, military vocabulary, character context and every required formatting token. Establish a glossary before batches; do not deduplicate dialogue solely by English text.

Statuses: untranslated, draft, translated, reviewed, in_game_verified, blocked, do_not_translate. Translation is not evidence of visual verification.

Public records retain stable IDs, resource/index, source SHA-256, Arabic, status and context metadata. Full English text remains in ignored local masters. Generate the local reference with AR above EN, including blank AR for untranslated entries. Never use presentation forms, reversed strings or PUA as the translation master.

The schema and placeholder grammar remain UNVERIFIED until source discovery. Do not invent game syntax or assign final IDs prematurely.

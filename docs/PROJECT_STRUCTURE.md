# Project structure

This document describes the repository layout, which areas are protected, and
which data is regenerable versus irreplaceable. Keep it current when the layout
changes.

## Root

- `README.md` — project overview, scope and status.
- `PROJECT_STATE.md` — authoritative state ledger and release-gate table.
- `DECISIONS.md` — dated engineering decisions with evidence (append-only).
- `ROADMAP.md`, `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  `LICENSE`, `THIRD_PARTY_NOTICES.md` — governance files.
- `requirements-pilot.txt` — pinned Python dependencies.
- `last_reporting.md` — local supervisor handoff (Git-ignored, local only).

Do not leave generated artifacts, archives, fonts or extracted game data at root.

## `.github/`

- `workflows/ci.yml` — Linux Python tests + public-repo guard, and the Windows
  app gates (`npm ci`, typecheck, lint, `cargo check/test/clippy`, production
  build) on every push and pull request.
- `workflows/release.yml` — tag-triggered build of the sidecar and NSIS
  installer, packaged-sidecar verification, manifest/checksums and GitHub Release.

## `app/`

- `src/` — React + TypeScript UI (`App.tsx`, pages, UI primitives, API wrapper).
- `src-tauri/` — Rust backend (`commands`, `game`, `backup`, `installer`,
  `payload`, `manifest`, `steam`, `state_store`, `config`, `types`, `version`) and
  Tauri config/capabilities/icons.
- `src-tauri/resources/sidecar/wtob-build.exe` — generated PyInstaller sidecar
  (Git-ignored, rebuilt by `tools/build_sidecar.py`).
- `README.md` — app build/architecture notes.

## `config/`

- `supported_versions.json` — the game-version gate: accepted vanilla hashes,
  the expected localized hashes, the executable hash and the supported Steam
  build. Unknown states must be refused.
- `pua_mapping.json` — tracked PUA code-point mapping (no font bytes); used by
  `tools/prepare_release_data.py` to regenerate the sidecar's build info.

## `release/`

- `README.md` — the release-asset contract.
- `release-manifest.json` / `release-manifest.template.json` — camelCase updater
  manifest (checked in for v1.0.0 and regenerated by CI for each tag) and its
  placeholder shape.

## `docs/`

- `discovery/` — reverse-engineering and extraction records.
- `fonts/` — font findings and Arabic rendering strategy.
- `localization/` — translation procedures and batch history.
- `build/` — build and installation procedures.
- `qa/` — quality gates.
- `distribution/` — distribution/licensing and research provenance.
- `PROJECT_STRUCTURE.md` — this file.

Cross-links use relative paths (`../fonts/FONT_SYSTEM.md`, etc.).

## `tools/`

All active Python tools stay **flat** in `tools/` (no subfolders) because tests add
`tools/` to `sys.path` and tools import each other flat.

Core pipeline:

- `archive_inventory.py`, `collect_text_corpus.py`, `audit_text_sources.py`
- `local_reference.py`, `apply_translation_batch.py`, `verify_translation_corpus.py`
- `formatted_text.py`, `pilot_font.py`, `bimage_codec.py`
- `build_runtime_localization.py`, `build_runtime_complete.py`,
  `verify_runtime_localization.py`, `verify_runtime_complete.py`
- `install_runtime_full.py`, `install_runtime_complete.py`
- `build_photosensitivity.py`
- `release_build.py` — sidecar entrypoint; builds from the user's own vanilla
  `chunk0` and validates every shipped English hash.
- `prepare_release_data.py` — regenerates `release_data/` from public partitions,
  `config/pua_mapping.json` and the hash-pinned OFL font.
- `build_sidecar.py` — PyInstaller one-file sidecar build with the reviewed
  exclude list.
- `make_release_manifest.py` — writes the camelCase updater manifest from a built
  installer.
- `check_public_repo.py` — public-repo safety guard (secrets, paths, assets,
  English leakage).

Historical pilots (kept for research/reproducibility):
`build_menu_pilot.py`, `install_menu_pilot.py`, `build_opening_poc.py`,
`install_opening_poc*.py`, `verify_opening_poc.py`, `build_subtitle_poc.py`,
`install_subtitle_poc.py`, `verify_subtitle_poc.py`, `fetch_pilot_font.py`.

Research-only tools (`bink2_decode.py`, `build_bink_audit.py`,
`build_coverage_inventory.py`, `inspect_bswf.py`) read the local game when the
`WTOB_GAME_DIR` environment variable is set. `classify_bink_audit.py` embeds
sampled English/credits text and is intentionally **not** tracked.

## `scripts/`

PowerShell uninstallers restore a specific pretest state. They take either a
`-GamePath "<game directory>"` parameter or the `WTOB_GAME_DIR` environment
variable; there are no hard-coded developer paths.

- `INSTALL_ARABIC.ps1` / `UNINSTALL_ARABIC.ps1` — legacy menu-pilot wrappers.
- `UNINSTALL_OPENING_POC*.ps1`, `UNINSTALL_SUBTITLE_POC.ps1`,
  `UNINSTALL_RUNTIME_FULL.ps1`, `UNINSTALL_RUNTIME_COMPLETE.ps1` — restore the
  matching pretest backup.

## `tests/`

Synthetic-only tests using `unittest`/`pytest` (`137` tests). No real game
fixtures are committed. Run:

```powershell
python -m unittest discover -s tests -v
python -m pytest tests -q
```

## `translation/` (public, tracked)

- `arabic/main_menu.json` — the 33-entry menu pilot.
- `arabic/phase_25.json`, `phase_50.json`, `phase_75.json`, `phase_100.json` —
  the confirmed-corpus batches. Each record has `id`, `resource`, `index`,
  `english_sha256`, `arabic`, `status`, `context`; the `english` field is
  intentionally empty. Never rewrite Arabic, IDs or source hashes.
- `glossary/GLOSSARY.md` — locked terminology.

## `reference/` (local authoritative, Git-ignored)

Generated via `python tools/local_reference.py`:

- `translation_master.local.jsonl` — canonical local bilingual master.
- `english_source.local.lang` — preserved original table bytes.
- `ALL_TRANSLATIONS.local.md`, `summary.local.json`.

## `reports/` (generated + historical)

Flat directory; active tools write `translation_phase_*.json`,
`translation_final_qa.json`, etc.

## `workspace/` — local only (Git-ignored)

Referenced by tool defaults, so names are stable. Key directories:

- `backups/` — **rollback keystone**: vanilla (`menu_pilot_original/`) and
  per-install pretest backups.
- `all_text/` — corpus (confirmed text + candidate literals).
- `text_audit/`, `inventory/`, `dialogue/` — extraction evidence.
- `linguistic_review/` — prior full review artefacts.
- `release_review/` — v1.0.0 review, language fixes and backups.
- `runtime_full/`, `runtime_complete/` — current build outputs.
- `runtime_full_reviewed/`, `runtime_complete_reviewed/` — previous review build.
- `research/` — IBM Plex Sans Arabic TTF (hash-pinned) and research sources.
- `experiments/` — crash evidence (never install the superseded builds).

## Important protected paths

- `workspace/backups/menu_pilot_original/` — vanilla backup (rollback).
- `reference/translation_master.local.jsonl`, `workspace/all_text/` — only copies
  of the bilingual corpus.
- `translation/arabic/` — public translation data.
- `docs/`, `PROJECT_STATE.md`, `DECISIONS.md` — reverse-engineering record.

## Generated vs irreplaceable

**Regenerable:** `workspace/inventory/`, `workspace/text_audit/`, dialogue data,
`reference/ALL_TRANSLATIONS.local.md`, `reference/summary.local.json`,
`reports/*` (validated by tools), build outputs.

**Irreplaceable / must back up:** the vanilla backup; the bilingual master and
corpus; `translation/arabic/*.json`; per-phase pre-apply backups.

Rule of thumb: anything under `reference/`, `workspace/all_text/` or
`translation/` is the only or authoritative copy — never bulk-delete.

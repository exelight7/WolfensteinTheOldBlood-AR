# تعريب Wolfenstein: The Old Blood

## التثبيت اليدوي — 1.0.1

1. أغلق اللعبة، وفك ضغط الحزمة في مجلد مستقل.
2. شغّل **Install.cmd**، ثم أدخل مسار مجلد اللعبة الذي يحتوي على **WolfOldBlood_x64.exe**.
3. انتظر اكتمال البناء والتثبيت، ثم شغّل اللعبة.

للعودة إلى النصوص الأصلية، شغّل **Restore.cmd** واختر مجلد اللعبة نفسه.

الحزمة تدعم نسخة Steam المحددة في المشروع. لا تحتاج Python أو Node أو اتصالًا بالإنترنت. تُبنى ملفات التعريب من نسختك الأصلية، وتُحفظ نسخة أصلية موثقة في مجلد **.WolfensteinAR-manual** داخل مجلد اللعبة؛ احتفظ به لاستعادة الأصل.

إذا كان التعريب مثبتًا مسبقًا، سيُطلب مجلد النسخة الاحتياطية الأصلية عند الحاجة. يجب أن يحتوي على الملفات الثلاثة الأصلية: **chunk0.index** و**chunk0.resources** و**graphicsdriverwarningloc.json**. عند فقدانها، تحقّق من سلامة ملفات اللعبة عبر Steam ثم أعد التثبيت. لا تُستبدل ملفات غير معروفة.

قد يلزم تشغيل التثبيت بصلاحيات المسؤول إذا منع Windows الكتابة في مجلد اللعبة. يحتاج البناء مساحة مؤقتة كافية للملفات والنسخ الاحتياطية؛ لا تغلق النافذة أثناء التثبيت.
